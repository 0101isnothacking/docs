Commands to discover live hosts on a network.

<Note>
  - `ip_network` = target network IP
  - `subnetmask` = /24 /22 /10
  - Example: `netdiscover -r 192.168.1.0/24`
</Note>

```bash
sudo arp-scan -i <interface>
sudo netdiscover -r <ip_network>/<subnetmask>
sudo nmap -sn <ip_network>/<subnetmask>
nmap -sn -iL hosts.txt
```
